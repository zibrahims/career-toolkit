# Organization

## Repositories

Online repositories kept for version control. Local copies should be made for working and then copied over to SSDs whenever working. Working off of SSDs (connecting/disconnecting) is really inefficient. 

- Personal: Website, CV
- Professional: __Private__ Toolkit
- Home: Recipes, __Public__ Best Practices + Toolkits

## Work

It is important to retain the following from work:

- References with contacts + regular outreach
- Evidence of work
  - Contributions
  - Knowledge
